Multi-page static website template for businesses. Developed with HTML5, CSS3, and vanilla JavaScript—no frameworks, no heavy dependencies. External libraries are consumed via CDN, and reusable components (navbar, footer) are implemented with native Web Components.

---

```bash
website/
│
├── assets/
│   ├── css/
│   │   ├── reset.css
│   │   └── global.css
│   ├── js/
│   │   └── global.js
│   └── img/
│
├── components/
│   ├── navbar.js        ← Web Component del navbar
│   └── footer.js        ← Web Component del footer
│
├── pages/
│   ├── inicio/
│   │   ├── index.html
│   │   ├── inicio.css
│   │   └── inicio.js
│   ├── empresa/
│   │   ├── index.html
│   │   ├── empresa.css
│   │   └── empresa.js
│   ├── servicios/
│   │   ├── index.html
│   │   ├── servicios.css
│   │   └── servicios.js
│   └── contactanos/
│       ├── index.html
│       ├── contactanos.css
│       └── contactanos.js
│
└── index.html
```
